# Educatech — versão inicial funcional

## Publicar no GitHub Pages
1. Abra seu repositório `educatech`.
2. Envie todos os arquivos desta pasta para a raiz do repositório (não envie a pasta ZIP dentro do repositório; envie os arquivos dela).
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
5. Aguarde o link do GitHub Pages ficar ativo.

## Incluído
- Interface responsiva para celular e desktop.
- Seis matérias e lições de múltipla escolha com explicações.
- XP, atividades concluídas e progresso guardados no navegador.
- Perfil local, código de turma local, preferência de ranking e exportação de dados.
- Manifesto e service worker para instalação/uso offline após o primeiro carregamento.

## Ainda não incluído
Login Google/e-mail, sincronização entre dispositivos, IA real, ranking global real, banco de dados, painel escolar com permissões, e APK. O ranking tem nomes de demonstração. Não coloque chaves secretas em `app.js` ou no APK. Essas integrações serão feitas depois com backend seguro e autenticação.
